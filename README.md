# 🛒 James Shopping Cart
## A fully functional shopping cart application built with vanilla JavaScript, HTML, and CSS.

### ✨ Features
-  Product Display - Grid layout showing 6 shoe products with images

-  Add to Cart - Add items with quantity tracking

-  Quantity Controls - Increase/decrease item quantities with +/- buttons

-  Delete Items - Remove individual items from cart

-  Like System - Heart-shaped button that turns red when clicked

-  Real-time Updates - Total price and cart badge update dynamically

-  Cart Persistence - localStorage saves cart between sessions

-  Empty State - Friendly message when cart is empty

-  Clear Cart - One-click empty cart with confirmation dialog

-  Slide-out Cart - Smooth animation when opening/closing

-  Fixed Navigation - Navbar stays visible while scrolling

###  🛠️ Technologies
-  HTML5

-  CSS3 (with CSS variables for theming)

-  Vanilla JavaScript (no frameworks)

-  Font Awesome 7 for icons

##  🚀 How to Use
###  Clone the repository

-  Open index.html in your browser

-  Click "Add To Cart" on any product

-  Click the shopping bag icon to view cart

-  Adjust quantities with +/- buttons

-  Click the heart to like items

-  Use "Delete" to remove individual items

-  Click "Clear Cart" to start over

###  🎯 Key Functions
-  addToCart() - Adds items or increments quantity

-  updateCart() - Refreshes display and totals

-  changeQuantity() - Handles +/- button logic

-  removeItem() - Deletes specific items

-  clearCart() - Empties entire cart with confirmation

-  saveCartToStorage() / loadCartFromStorage() - Persists data
